# 配置文件说明

## 📁 配置文件结构

```
fitness-server/
└─ src/main/resources/
    ├─ application.yml                    # ✅ 公开配置（可提交到Git）
    ├─ application-local.yml              # ❌ 私密配置（不提交，包含真实密钥）
    └─ application-local.yml.example      # ✅ 模板文件（可提交到Git）
```

---

## 🚀 快速开始

### 首次使用

1. **复制模板文件**
   ```bash
   cd fitness-server/src/main/resources
   copy application-local.yml.example application-local.yml
   ```

2. **编辑 application-local.yml**
   
   打开 `application-local.yml`，填入真实的配置：
   ```yaml
   spring:
     datasource:
       password: 你的数据库密码
   
   jwt:
     secret: 你的JWT密钥（至少32位）
   
   deepseek:
     api-key: 你的DeepSeek_API_KEY
   ```

3. **启动项目**
   ```bash
   cd fitness-server
   mvn spring-boot:run
   ```

## 🔒 安全说明

### 为什么这样做？

**问题**：直接把密钥写在 `application.yml` 中，提交到 Git 后所有人都能看到。

**解决方案**：
- `application.yml` - 只包含公开配置（可提交）
- `application-local.yml` - 包含真实密钥（不提交，已在 `.gitignore` 中）

### 配置加载顺序

Spring Boot 会按顺序加载配置，后面的覆盖前面的：

1. 先加载 `application.yml`（公开配置）
2. 再加载 `application-local.yml`（私密配置，覆盖第1步）

**结果**：真实密钥生效，但不会提交到 Git。

## 📝 配置项说明

### 1. 数据库密码
```yaml
spring:
  datasource:
    password: 你的MySQL密码
```

**获取方式**：你安装 MySQL 时设置的 root 密码

---

### 2. JWT 密钥
```yaml
jwt:
  secret: 至少32位的随机字符串
```

**作用**：用于签名用户登录令牌（Token）

**生成方式**：随便打一串字符，越长越安全，例如：
```
fitness-app-jwt-secret-2024-random-key-for-token-signature
```

---

### 3. DeepSeek API KEY
```yaml
deepseek:
  api-key: sk-xxxxxxxxxxxxxxxxxxxxxx
```

**获取方式**：
1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/)
2. 注册/登录账号
3. 进入"API Keys"页面
4. 点击"创建新密钥"
5. 复制生成的密钥（格式：`sk-xxxxxx`）

## ❓ 常见问题

### Q1: 启动时报错"密钥不能为空"
**原因**：没有创建 `application-local.yml` 或密钥为空

**解决**：
1. 检查 `src/main/resources/` 目录是否有 `application-local.yml`
2. 确认文件中密钥不为空

---

### Q2: 修改了配置不生效
**原因**：可能修改了错误的文件

**解决**：
- 公开配置：修改 `application.yml`
- 密钥配置：修改 `application-local.yml`

---

### Q3: Git 提示要提交 application-local.yml
**原因**：`.gitignore` 配置可能有问题

**解决**：
1. 检查项目根目录的 `.gitignore` 文件
2. 确认包含这一行：`application-*.yml`
3. 如果已经提交过，需要从 Git 中移除：
   ```bash
   git rm --cached fitness-server/src/main/resources/application-local.yml
   git commit -m "移除敏感配置文件"
   ```

---

### Q4: 换电脑后配置丢失了
**原因**：`application-local.yml` 不会提交到 Git，只存在于本地

**解决**：
1. 在新电脑上重新创建 `application-local.yml`
2. 从密码管理器或团队文档中获取密钥
3. 或重新生成 DeepSeek API KEY

---

## 🎯 最佳实践

### ✅ 推荐做法

1. **密钥管理**
   - 使用密码管理工具（如 1Password、LastPass）保存密钥
   - 团队使用统一的密钥管理平台

2. **定期轮换**
   - 定期更换 DeepSeek API KEY
   - 定期更换 JWT 密钥（需要用户重新登录）

3. **环境隔离**
   - 开发环境：`application-local.yml`
   - 测试环境：`application-test.yml`
   - 生产环境：`application-prod.yml` 或环境变量

---

### ❌ 避免做法

1. ❌ 不要把 `application-local.yml` 提交到 Git
2. ❌ 不要通过聊天软件直接发送密钥（容易泄露）
3. ❌ 不要在多个项目使用相同的密钥
4. ❌ 不要把密钥截图发给别人
